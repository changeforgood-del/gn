# 2026 Fresno AIDS Walk Sponsorship Tracker

Interactive browser-based command center for the 15th Annual Fresno AIDS Walk sponsorship effort.

## Event
- Saturday, November 7, 2026
- 8:00 AM
- Woodward Park — North East 12 Acres, Fresno
- Sponsor logo/material deadline: September 18, 2026

## What the app tracks
- Confirmed sponsors and known cash/in-kind value
- Calls, voicemails, emails and responses
- Online applications and application status
- Team assignments and who worked each contact
- Next actions and follow-up needs
- Sponsor/contact locations with clickable map view
- Timeline of sponsorship work
- Visual pipeline, owner workload and hidden-risk breakdowns
- Printable next-meeting progress update with assignments and attention items
- Local record editing in the browser
- JSON export/import backups

## Open the app
Open `index.html` in this folder.

If GitHub Pages is enabled for this repository, the app can be served as a static website under the `/faw-2026/` path.

## Data note
The source project files contain workflow queue counts that overlap. Email, call, research and application counts should not be summed as a unique sponsor total.

## Current data baseline
The app includes documented sponsorship work through September 1, 2026 and can be updated directly in the browser. Browser changes are stored in localStorage on the device, so use **Export JSON** for backups and **Import JSON** to restore or move the tracker to another device.
